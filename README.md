# Tugas-IoT
Sistem IoT Smart Green House dapat melakukan pengairan pada tanaman saat kelembapan tanah berada di bawah ambang batas tertentu dan pada waktu tertentu, serta menyalakan kipas untuk mendinginkan udara di dalam greenhouse jika suhu udara di dalam greenhouse terlalu panas. Sistem juga dapat membaca level air di dalam tandon, dan tidak melakukan pengairan (pompa tidak menyala) apabila air di dalam tandon terlalu sedikit.

Sistem ini menggunakan dua edge device, di mana edge device pertama memantau kelembapan dan suhu udara serta intensitas Cahaya, dan menyalakan aktuator kipas. Sedangkan edge device kedua digunakan untuk memantau kelembapan tanah dan level air di tandon, dan menyalakan aktuator pompa air.
